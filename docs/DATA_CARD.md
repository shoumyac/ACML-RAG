# Data card

## Contents

| Folder | What it holds |
|---|---|
| `data/controlled/` | Generations on the controlled two-regime fact world (synthetic facts with no parametric knowledge, real facts with it) across a typed-noise grid, nine generators |
| `data/naturalistic/` | SQuAD with real BM25 and dense retrieval, plus natural-noise runs |
| `data/judged/` | LLM-judge relabeled generations and `human_annotation_sheet.csv` |
| `data/reports/` | Per-model JSON reports: AUROC, semantic-entropy gap, conformal results |

## Record schema (`results_*.json`)

One record per generation:

| Field | Meaning |
|---|---|
| `qid`, `regime`, `cond` | question id, content regime, noise condition |
| `question`, `gold`, `answer` | prompt, reference answer, model answer |
| `label` | `correct`, `hallucination` or `abstain` |
| `ret_mean`, `ret_top1`, `ret_margin`, `ret_min`, `ret_std`, `has_ctx`, `conflict`, `n_claims` | retrieval descriptors |
| `lp_mean`, `lp_min`, `ent_mean`, `ent_max`, `ent_first`, `ans_len` | model-internal features |
| `d_lp`, `d_ent`, `ans_changed` | closed-book contrast |
| `se` | discrete semantic entropy (where computed) |

`judged_*.json` additionally carry `label_em` (the exact-match label) next to the judge `label`.

## Provenance and licensing

Generations come from openly licensed models run by the authors. Questions in the naturalistic data come from SQuAD (CC BY-SA 4.0). The synthetic fact world is generated by `code/build_world_v2.py` and `code/build_world_domain2.py`. No personal data is included.

## Known caveats

Exact-match labels undercount paraphrase hallucination (the judged files quantify this). The poisoning conditions use one recipe each. Generators go up to 14B parameters.
